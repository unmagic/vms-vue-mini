<h1 align="center">VMS Vue Mini</h1>

VMS Vue Mini 是一个基于 [Vue Mini](https://github.com/vue-mini/vue-mini) 的小程序框架，专门针对VMS编译器进行特殊优化。

## 开始

```bash
npm install @vms/vue-mini
```
